# Changelog

## 1.2.1+port.2

- Mailboxes for the woods of Biomes O' Plenty, Ecologics and Wilder Wild. They appear only when that
  mod is installed, with the usual recipe (planks, a chest and a fence) and a look made from the
  wood's planks. Nothing changes for worlds without those mods.

## 1.2.1+port.1

The first release of the unofficial port. It is Mighty Mail 1.2.1 by MrCrayfish, brought to
Minecraft 26.3 for Fabric and NeoForge.

- Everything the original does: a post box, mailboxes in every wood type, packages with messages,
  delivery across dimensions, the red flag for waiting mail, and the server config options.
- Worlds coming from the original mod on 1.21.10 or older keep their mailboxes, names, owners and
  queued mail: the port imports the old mailbox registry the first time the world starts.
- The mod id is unchanged (`mighty_mail`), so the port is a drop-in replacement.
